# 🌾 AgroBridge – Agricultural Management System

AgroBridge is a C# desktop-based application designed to simplify agricultural activities by connecting farmers, customers, workers, and donors through a centralized platform.

The system provides various agricultural services, including product trading, equipment rental, agricultural waste management, worker hiring, and donation management.

## Key Features

- **User Management:** Registration, login, and profile management for different user roles.
- **Agricultural Goods Market:** Farmers can manage and sell agricultural products, while customers can browse and purchase goods.
- **Waste Management:** A dedicated marketplace for agricultural waste trading.
- **Equipment Rental:** Browse farming equipment with rental prices and availability information.
- **Worker Hiring:** Farmers can find and hire workers based on their skills and availability.
- **Donation Management:** Donation applications with administrative review and approval management.
- **Shopping Cart & Checkout:** Manage selected products, checkout, and purchase orders.
- **Order Management:** Track purchases, sales, and rental orders.
- **Admin Dashboard:** Manage users, monitor system activities, and handle donation requests.

## Database Management

The application uses database integration to manage users, agricultural products, waste records, equipment, transactions, worker information, and donations.

The database design includes structured tables and relationships to organize application data.

## Technologies Used

- C#
- .NET
- Desktop GUI
- Database Integration

## Application Overview

AgroBridge brings essential agricultural services together in one desktop application, helping streamline farming-related transactions, resource management, and collaboration.
